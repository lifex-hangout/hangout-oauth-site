# Hangout OAuth homepage

Public homepage for the Hangout - Date & Find Friends OAuth branding review.

The English privacy policy and terms of service are copied without content changes from the `lifex-hangout/static` repository. The copies use Jekyll front matter so GitHub Pages renders them as readable HTML pages.

This project site is intended for a custom subdomain of `beesk.it`, whose domain property is verified in Google Search Console. Keep its homepage, privacy policy, and terms links on that same subdomain when configuring Google Auth Platform branding.
